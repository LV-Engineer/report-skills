# report-skills

Версійований, портативний набір Agent Skills для форматування навчальних звітів
(.docx) за правилами конкретної кафедри/спеціальності. Репозиторій — єдине джерело
правди для цих правил (замінює будь-який попередній Notion-варіант); зручно
поширювати іншим людям незалежно від того, як у них організовані власні файли.

## Що тут є

```
skills/
  format-lab-reports/
    SKILL.md        # процедура: коли й що робити, покроково
    reference.md     # самі правила оформлення (шрифти, поля, нумерація тощо)
```

Кожен тип роботи (лабораторна/практична, курсова, звіт з практики...) — окрема
папка під `skills/` зі своїм `SKILL.md` і `reference.md`. Один skill = один тип
роботи; не змішувати правила різних типів робіт в одному skill.

## Принцип SKILL.md vs reference.md

- **SKILL.md** — процедура і контракт (у якому порядку робити кроки, хто перевіряє,
  коли питати користувача). Змінюється рідко — лише коли міняється сам workflow.
- **reference.md** — фактичні правила оформлення (цифри, формати, приклади).
  Змінюється частіше — коли кафедра/викладач оновлює вимоги. `SKILL.md` завжди
  читає `reference.md` заново перед виконанням, а не покладається на пам'ять.

## Як підключити (незалежно від вашої файлової структури)

Цей репозиторій не прив'язаний до конкретних шляхів на диску — він лише містить
правила й процедуру. Самі звіти можуть лежати де завгодно.

- **Claude Desktop / Cowork**: скопіюйте потрібну папку зі `skills/` у свій
  workspace (наприклад, у `.skills/skills/` тієї папки, з якою працює Cowork), або
  просто вкажіть Cowork шлях до цього репозиторію як додаткове джерело контексту.
- **Claude Code**: скопіюйте папку skill'а в `.claude/skills/` вашого проєкту.
- **Без інтеграції**: відкрийте `SKILL.md` потрібного skill'а і попросіть Claude
  виконати описані там кроки, додавши сам файл .docx.
